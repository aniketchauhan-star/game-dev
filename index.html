NEXUS Play Studio

Looking for the running studio on this computer…

This page is served by a static file server (for example VS Code’s Live Server), which cannot run the studio. NEXUS Play Studio is a local app with a server and a background worker.

  1. In a terminal in this folder, run npm install (first time only).
  2. Run npm run dev.
  3. Open http://127.0.0.1:5173 — this page also opens it by itself once it is running.

Production-style instead: npm run build, then npm start, and open http://127.0.0.1:5174.

Live Server is not needed for NEXUS — you can stop it from the VS Code status bar.
