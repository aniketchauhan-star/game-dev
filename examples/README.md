# Example exports

Produced by NEXUS Play Studio through its own API from a fresh data directory, without a Claude key.

| File | What it is |
| --- | --- |
| `exports/air-traffic-control-playable.zip` | Playable game for the bundled sample (demo content). Unzip and open `index.html`, or serve the folder from any static host or sub-folder. |
| `exports/air-traffic-control-source.zip` | Source package: `game.config.json`, asset map and originals, runtime and its TypeScript source, `build.mjs` / `serve.mjs`. |
| `exports/air-traffic-control-claude-handoff.zip` | Claude Code handoff: the source package plus `README.md`, `CLAUDE.md`, `GAME_DESIGN.md`, `TASKS.md`, `ASSET_GUIDE.md`, `blueprint.json`, `source-map.json`, `PREFLIGHT.md`. |
| `exports/quadrant-memory-developer-handoff.zip` | Developer handoff for a blueprint-only idea (a memory-card mechanic the studio cannot build): approved design, tasks and runtime source — no game config or build script, because there is no playable game yet. |

None of them contain the source deck, speaker notes, conversations or keys (each includes its `PREFLIGHT.md`).
Regenerate them by exporting from the studio (**Export** in the top bar).
